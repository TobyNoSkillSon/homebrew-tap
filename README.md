# Homebrew tap

```sh
brew install --cask tobynoskillson/tap/vella
```

[Vella](https://github.com/TobyNoSkillSon/Vella): offline dictation and live transcription for Apple Silicon Macs, macOS 26 or newer. The cask follows each published Vella release.

```sh
brew install --cask tobynoskillson/tap/heimdall-alpha
```

[Heimdall](https://github.com/TobyNoSkillSon/Heimdall): an assistant you talk to that sees and hears your Mac, Apple Silicon, macOS 14.4 or newer (26 recommended). Alpha; the cask follows each published alpha.
